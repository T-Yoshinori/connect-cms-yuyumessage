# YuyuMessage — Connect-CMS用メッセージプラグイン

ログインユーザー同士で、1対1・利用者が作成するグループ・CMS所属グループのメッセージを交換します。Connect-CMS 1.44.1を基準にしたβ版です。CMS本体は含みません。

## ダウンロード

[新規インストール用 downloads.zip](https://github.com/T-Yoshinori/connect-cms-yuyumessage/raw/main/downloads.zip)

ZIPの中の `connect-cms-yuyumessage` フォルダーを開き、`app`・`config`・`database`・`public`・`resources` を、Connect-CMSの同じフォルダーへ配置してください。`docs` は説明書です。

## 主な機能

- 相手をユーザー名で検索して追加。全ユーザー一覧は表示しません。
- 任意グループの作成・参加者管理・管理引継ぎ・退会。途中参加者は参加以降の投稿を閲覧できます。
- 画像・動画・ファイルの添付、スマホ撮影、現在地の送信、URLの自動リンク化。
- いいね、本人による編集・削除、既読表示と未読バッジ。
- 閲覧中の新着ポップアップと、新規メッセージ送信時のメール通知。
- 管理画面から添付制限、編集可能時間、メール通知間隔、保存期間を設定。

会話への参加権限で閲覧を制御します。CMS管理者という理由だけで他人の会話を閲覧できません。本文・位置情報・任意グループ名・添付データは既存の `APP_KEY` で暗号化します。DB・サーバーを直接操作する保守管理者を制限する仕組みではありません。

## 新規インストール

既存のConnect-CMSをバックアップしてから実施してください。ファイル配置とコマンド実行は導入担当者が行い、日常の設定は管理画面で行えます。

1. 上記の各フォルダーを、既存CMSの同じパスへ配置します。CMS本体のファイルや `.env` を置き換える作業はありません。
2. CMSのルートで次を実行します。

```sh
php artisan migrate
php artisan db:seed --class=YuyuMessagePluginSeeder
php artisan config:clear
php artisan view:clear
```

3. プラグイン管理で「YuyuMessage」が表示されることを確認し、ログイン利用者が閲覧できるメッセージ用ページのメインエリアに配置します。バケツの作成は不要です。
4. テーマ設定で、追加CSSテーマ・追加JavaScriptテーマの両方に「YuyuMessage通知」を選びます。メッセージページにも適用します。
5. 管理画面のテーマ管理から、YuyuMessage通知のCSS編集・JavaScript編集を開いて保存します。ファイル転送後に古いテーマキャッシュが残る場合も、この保存で反映します。ページ番号・フレーム番号をJSへ書き込む必要はありません。
6. フレーム編集の「運用設定」を開き、必要な値を保存します。「運用設定を保存しました。」の表示を確認してください。「キャンセル」でメッセージ画面へ戻れます。

新規導入ではテーブル作成のためmigrationが必要です。既にYuyuMessageのテーブルを導入済みのサイトとは区別してください。既存の `APP_KEY` は変更せず、DBと一緒に保管してください。既存サイトで `php artisan key:generate` は実行しないでください。

## 既存の独自テーマへ通知部品を組み込む

提供するテーマファイルは次の3点です。

```text
public/themes/Users/YuyuMessage/themes.ini
public/themes/Users/YuyuMessage/themes.css
public/themes/Users/YuyuMessage/themes.js
```

独自テーマを使い続ける場合は、テーマ管理の「YuyuMessage通知」のCSS編集画面から内容をコピーし、使用中の独自テーマのCSS編集画面の末尾へ追加して保存します。JavaScriptも同様に、提供テーマの全内容を独自テーマのJavaScript編集画面の末尾へ追加して保存します。既存の内容は残してください。同じ内容を二重に追加しないでください。

CSSとJSは会話画面・添付・通知をまとめた構成です。別のローダーや番号設定ファイルは不要です。以後の編集・更新もブラウザー上のテーマ管理で行えます。テーマの `YuyuMessage` は大文字小文字を含めて一致させてください。

## 運用設定と初期値

|設定|初期値|
|---|---|
|メール通知|使う|
|同じ受信者への最短メール通知間隔|60分|
|画像・動画・一般ファイルの添付|許可|
|1点の容量上限|画像10MB・動画50MB・一般ファイル20MB|
|1メッセージの添付上限|5点・合計50MB|
|編集可能時間|15分（0で編集不可）|
|保存期間|無期限|

添付の許可形式も選択できます。変更は新規送信へ適用し、既存添付は引き続き閲覧・ダウンロードできます。容量はサーバーのPHPアップロード上限にも制限されます。詳しくは [運用設定の説明](docs/yuyu-message-operations.md) を参照してください。

保存期間を設定しただけでは削除しません。設定画面で期限切れの件数・添付数・合計容量を確認し、確認チェックを入れて手動で削除します。本文や参加者名は管理用の集計に表示しません。1回最大100メッセージで、残りがあれば再実行します。削除は取り消せません。削除表示・再送防止のための最小限の記録は残ります。

## 通知とメール

テーマを適用したページでは、右下の「メッセージ」ボタン・未読バッジ・新着ポップアップから会話を開けます。通知だけで既読にはしません。会話は標準5秒、一覧と通知は標準30秒で取得し、非表示タブでは停止します。Push通知ではありません。

メールは新しいメッセージを保存した直後に送ります。最短間隔内は省略し、省略分を後から自動送信しません。cron・定期実行・キューワーカーは不要です。運用者が通知の有効・無効と間隔を設定し、受信者は個別に受取りを辞退できます。

CMSの既存メール設定を使用します。CMSでメールを送信できることを事前に確認してください。案内メールには本文・送信者名・会話名・位置・添付を載せず、メッセージページへのリンクを載せます。メールに失敗しても投稿は保存され、送信画面に警告を表示します。SMTPが遅い場合やグループ人数が多い場合は応答にも時間がかかります。

## スマホ・添付・現在地

「＋」から画像・動画・ファイル・撮影・現在地を選択します。現在地はHTTPSと端末の位置情報許可が必要です。標準で推定誤差100mを超える結果は送信できません。実際の住所へ補正する機能ではなく、送信前に地図で確認してください。

添付は参加権限を確認して配信します。表示・再生できるかは端末と形式に依存し、対応しない形式はダウンロードして開きます。HTTP/HTTPSのURLを本文へコピペするとリンクになります。ページタイトルや画像の自動取得は行いません。

## 更新と確認

更新時は同じパスのファイルを差し替え、`config:clear` と `view:clear` を実行します。テーマCSS/JSもテーマ管理で新版を保存してください。独自テーマへコピーした場合は、その中のYuyuMessage部分を更新します。

2つのアカウントで双方向の送受信、未読・既読、通知、添付表示・保存、メール受信、途中参加以降の閲覧を確認してください。保存期間による削除は、消してよいテストデータで先に確認してください。
