# YuyuMessage 運用設定と手動整理

## 運用者の操作

YuyuMessageフレームの編集を開き、設定メニューの「運用設定」を選ぶ。CMSのフレーム編集権限が必要。サイト内のすべてのYuyuMessageに共通する設定で、管理権限があっても他人の本文を表示する機能は設けない。

| 設定 | 初期値・指定範囲 |
|---|---|
| メール通知 | 使う。受信者は個人で受取りを辞退できる |
| 同じ受信者への最短通知間隔 | 60分。1〜1440分 |
| 画像・動画・一般ファイル | それぞれ許可／禁止 |
| 許可する形式 | システム対応形式のチェックボックス。任意の拡張子は追加できない |
| 画像1点の容量 | 10MB。1〜1000MB |
| 動画1点の容量 | 50MB。1〜1000MB |
| 一般ファイル1点の容量 | 20MB。1〜1000MB |
| 1メッセージの添付数 | 5点。1〜20点 |
| 1メッセージの合計容量 | 50MB。1〜1000MB |
| 送信後の編集時間 | 15分。0〜1440分。0は編集不可 |
| 保存期間 | 空欄＝無期限。1〜36500日 |

保存成功時は「運用設定を保存しました。」と表示する。キャンセルでメッセージ画面に戻る。環境ファイルやソースを運用者が編集する必要はない。既存CMSの設定テーブルへ保存する。

添付の種類・形式・容量・数の変更は新規送信に適用する。以前送った添付の閲覧・ダウンロードは維持する。サーバー側でも検証し、ブラウザーの制限を外して送信しても許可しない。PHPやWebサーバーのアップロード上限を超える容量にはできないため、実際の許容量は両方の制限の小さい方になる。

編集時間の変更は次の編集・画面取得から適用し、既存の投稿も送信時刻からその時間で判定する。本人による削除は従来どおり可能。

## 保存期限を過ぎたデータの整理

保存期間を設定・保存しただけではデータを削除しない。設定画面の下部に削除対象の境界時刻、メッセージ件数、添付件数、元データの合計容量を表示する。本文、ユーザー名、会話名、ファイル名、位置情報は表示しない。

内容を確認し、取り消せないことを確認するチェックを入れて「確認した期限切れデータを削除」を押す。1回で最大100メッセージを処理し、残り件数を表示する。残っていれば改めて確認して実行する。無期限の間は削除できない。保存期間変更時・確認後10分経過時は、確認し直す。確認した後に作成されたメッセージや、その後に期限が来たメッセージを同じ確認で追加削除しない。

対象はサイト全体の古いメッセージ。本文・位置情報の暗号文、いいね、添付の名称情報・実ファイルを削除する。画面の削除表示、会話内の順序、既読境界、重複送信防止のためにメッセージID・送信者ID・送信UUIDのハッシュなど最小限の記録を残す。会話や参加履歴そのものは削除しない。

実ファイル削除に失敗した場合も、本文・添付のアクセスは先に無効にする。失敗したファイルの保存キーを残し、次の手動整理で再試行する。処理結果に未完了件数を表示する。DBバックアップ等の外部コピーから消す機能ではない。

自動削除、cron、定期実行の登録は不要。この段階では運用者による手動整理のみ。

## 導入時に配置・差し替えるファイル

新規:

- `app/Plugins/User/Yuyumessage/Services/MessageOperationsService.php`
- `app/Plugins/User/Yuyumessage/Services/MessageRetentionService.php`

差し替え:

- `app/Plugins/User/Yuyumessage/YuyumessagePlugin.php`
- `app/Plugins/User/Yuyumessage/Services/MessageAttachmentService.php`
- `app/Plugins/User/Yuyumessage/Services/MessageRecordService.php`
- `resources/views/plugins/user/yuyumessage/default/mail_settings.blade.php`
- `resources/views/plugins/user/yuyumessage/yuyumessage_frame_edit_tab.blade.php`
- `public/themes/Users/YuyuMessage/themes.js`

テンプレート名 `mail_settings.blade.php` と保存アクション名は既存サイトとの互換のため維持しているが、画面は全運用設定を扱う。

DBの追加・変更はなく、`migrate` は不要。配置後に `php artisan view:clear`。JSはテーマ管理のJavaScript編集から新版を保存する。既存独自テーマに組み込んでいる場合は、その中のYuyuMessage部分を差し替える。CSSの変更はない。

## 確認事項

1. 運用者が設定を保存でき、一般利用者は変更・整理できないこと。
2. 添付種類を禁止すると新規の選択・送信はできず、既存の添付は保存できること。
3. 形式・容量・数の設定が新規送信へ反映されること。
4. 編集時間を0にすると編集できないこと。
5. 保存期間を設定しても、その時点では削除されないこと。
6. 削除対象確認に本文・参加者名が表示されないこと。
7. 検証環境で期限切れデータと添付を整理し、期間内の投稿が残ること。

本番の削除確認は、対象件数とバックアップ運用を確認したうえで行う。テスト用の古いデータだけで先に動作確認する。
